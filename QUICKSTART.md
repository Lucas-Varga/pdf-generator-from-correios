# ⚡ INÍCIO RÁPIDO

## 3 passos simples para testar:

### 1. Instalar dependências
```bash
cd backend
npm install
```

### 2. Iniciar servidor
```bash
npm start
```

Esperar aparecer:
```
✓ Servidor rodando em http://localhost:3000
```

### 3. Abrir no navegador
```
http://localhost:3000/document/index.html
```
